## 📋 О моде

**RP-MXTR-RMT** (ранее — RP-MXTR-RPGA) — ролевой мод для Minecraft 1.21.10
на Fabric. Превращает ванильную игру в RP: оружие и патроны, смартфон с
приложениями, фракции с формой и рангами, 3D-транспорт, тюрьма и полиция,
жажда и температура, документы, NPC, админ-панель, баг-репорты прямо из игры.

## 🚀 Установка

### Одиночная игра

1. Установи **Fabric Loader ≥ 0.16.9** для Minecraft **1.21.10**
2. Положи в папку `mods/`:
   - [RP-MXTR-RMT-61.9.0.jar](RP-MXTR-RMT-61.9.0.jar)
   - [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.10
3. Запусти игру

### Сервер

1. Установи Fabric Loader + Fabric API на сервер
2. Положи **тот же jar** в папку `mods/` сервера
3. Версия мода на клиенте и сервере должна **совпадать**

> 📘 Гайды: [Для игроков](../../docs/PLAYER-GUIDE.md) · [Для администраторов](../../docs/ADMIN-GUIDE.md)

## ⌨️ Управление

| Клавиша | Действие |
|---|---|
| `R` | Перезарядка оружия |
| `H` | Сесть (на ступени, заборы) / гудок в машине |
| `F` | Контекстное действие: места в машине, меню наручников, замки, фонарик |
| `W`/`A`/`S`/`D` | Вождение |
| `P` | Ручник |
| `L` | Фары |
| `Shift` | Выход из машины |
| ЛКМ | Стрельба, ограбление, струя из рукава |
| ПКМ | Разговор с NPC, гидрант, ключ машины |

## ⌨️ Основные команды

```
/rmt menu          — главное меню
/rmt admin         — админ-панель (для админов)
/rmt balance       — баланс
/rmt thirst        — уровень жажды
/rmt faction info  — информация о фракции
/rmt report <текст> — отправить репорт
/skin set <ник>    — скин по нику Mojang
/skin url <ссылка> — скин по URL (MineSkin)
```

Полный список — в [ADMIN-GUIDE.md](../../docs/ADMIN-GUIDE.md).
