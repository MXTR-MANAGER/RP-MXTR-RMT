## 📋 О моде

**RP-MXTR-RMT** (ранее — **RP-MXTR-RPGA**) — ролевой мод, превращающий
ванильный Minecraft в полноценную RP-игру: фракции с рангами и формой,
живые NPC с работой и торговлей, 3D-транспорт на реальных OBJ-моделях,
оружие с патронами и гильзами, тюрьма и полиция, жажда и температура,
документы, смартфон с приложениями, собственные звуки и встроенные
баг-репорты прямо из игры.

## 🚀 Быстрый старт

1. Скачай **[RP-MXTR-RMT-61.9.0.jar](versions/61.9.0/RP-MXTR-RMT-61.9.0.jar)**
2. Установи [Fabric Loader ≥ 0.16.9](https://fabricmc.net/use/) для Minecraft 1.21.10
3. Положи в `mods/` мод + [Fabric API](https://modrinth.com/mod/fabric-api)
4. Запусти игру — при первом входе мод попросит задать пароль

Подробности и установка на сервер — в [описании версии](versions/61.9.0/README.md).
