## 🚀 Установка

### Одиночная игра

1. Установи [Fabric Loader ≥ 0.16.9](https://fabricmc.net/use/) для **Minecraft 1.21.10**
2. Скачай **[RP-MXTR-RMT-61.9.0.jar](../versions/61.9.0/RP-MXTR-RMT-61.9.0.jar)** и [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.10
3. Положи оба файла в папку `mods/`:
   - Windows: `%APPDATA%\.minecraft\mods\`
4. Запусти игру с профилем **fabric-loader-1.21.10**

### Сервер

1. Установи Fabric Loader + Fabric API на сервер
2. Положи **тот же jar** в `mods/` сервера
3. ⚠️ Версия мода на клиенте и сервере должна **совпадать** — иначе будут
   проблемы с подключением

### Требования

| | |
|---|---|
| Minecraft | **1.21.10** |
| Fabric Loader | **≥ 0.16.9** |
| Fabric API | свежая для 1.21.10 |
| Java | **21+** |
| Место | ~7 МБ |

## 🔑 Первый вход

При первом подключении к серверу мод попросит **задать пароль** — это вход в
RP-профиль (баланс, фракция, документы, телефон привязаны к нему).

- Забыл пароль — попроси админа: `/rmt resetpass` (см. [гайд админа](ADMIN-GUIDE.md))
- Пытался подобрать чужой пароль — действия блокируются

## ⌨️ Управление

| Клавиша | Действие |
|---|---|
| `R` | Перезарядка оружия |
| `H` | Сесть (ступени, заборы, края) |
| `F` | Фонарик |

Настройка клавиш — стандартное меню Minecraft: *Настройки → Управление*.

## 📱 Смартфон

Открывается из хотбара (предмет телефона). Приложения:

| Приложение | Что делает |
|---|---|
| 🏦 **Банк** | Баланс, переводы, история |
| ☎️ **Звонки** | Звонки другим игрокам |
| 💬 **Чаты** | Личные сообщения, список чатов |
| 👥 **Друзья / Контакты** | Заявки в друзья, контакты |
| 🧭 **Навигатор** | Точки на карте (админы ставят через блок навигационной точки) |
| 🌐 **Даркнет** | Доступ только в розыске |
| 🚨 **Полиция / Криминал** | Профиль, розыск, вызовы |
| 📷 **Фото** | Камера, галерея скриншотов |
| 📻 **Радио** | Частоты фракций |
| 👤 **Профиль** | ФИО, документы, лицензии |

## 🌡 Выживание

- 💧 **Жажда** — пей воду, иначе начнёшь терять силы. Проверка: `/rmt thirst`
- 🌡 **Температура** — одевайся по погоде (форма фракций тоже греет/защищает)
- 🎒 **Рюкзак** — дополнительное место для вещей
- 🔭 **Бинокль** — приближение (прицел + использование)
- 🔦 **Фонарик** — клавиша `F`

---

## 🔫 Оружие и боеприпасы

- Оружие (АК-47, AWP и другое) требует **патроны соответствующего калибра**
- Перезарядка — клавиша `R`
- Гильзы выпадают при стрельбе
- **Лицензия на оружие** оформляется как документ — без неё ношение =
  проблемы с полицией

---

## 🚔 Фракции

5 фракций с формой и рангами: **ДПС, ФСБ, ФСО, Медицина, Армия**.

- Вступление — по приглашению (лидер/админ)
- У каждой фракции: своя форма, ранги, панель управления, фракционная бочка
- Фракционные действия: вызовы (`/rmt accept_call`), больница, розыск

---

## ⛓ Полиция и розыск

- Нарушения дают **звёзды розыска** — тебя ищет полиция
- Наручники, обыск, тюрьма, штрафы
- В розыске открывается **даркнет** в телефоне
- Отсидел срок или заплатил штраф — розыск снят
