## 🚀 Установка

### Одиночная игра

1. Установи [Fabric Loader ≥ 0.16.9](https://fabricmc.net/use/) для **Minecraft 1.21.10**
2. Скачай **[RP-MXTR-RMT-61.9.0.jar](../versions/61.9.0/RP-MXTR-RMT-61.9.0.jar)** и [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.10
3. Положи оба файла в папку `mods/`:
   - Windows: `%APPDATA%\.minecraft\mods\`
4. Запусти игру с профилем **fabric-loader-1.21.10**

### Сервер

1. Установи Fabric Loader + Fabric API на сервер
2. Положи **тот же jar** в `mods/` сервера
3. ⚠️ Версия мода на клиенте и сервере должна **совпадать** — иначе будут
   проблемы с подключением

### Требования

| | |
|---|---|
| Minecraft | **1.21.10** |
| Fabric Loader | **≥ 0.16.9** |
| Fabric API | свежая для 1.21.10 |
| Java | **21+** |
| Место | ~7 МБ |

## 🔑 Первый вход

При первом подключении к серверу мод попросит **задать пароль** — это вход в
RP-профиль (баланс, фракция, документы, телефон привязаны к нему).

- Забыл пароль — попроси админа: `/rmt resetpass` (см. [гайд админа](ADMIN-GUIDE.md))
- Пытался подобрать чужой пароль — действия блокируются

## ⌨️ Управление

| Клавиша | Действие |
|---|---|
| `R` | Перезарядка оружия |
| `H` | Сесть (ступени, заборы, края) / гудок в машине |
| `F` | Контекстное действие: места в машине, меню наручников, замки, фонарик |
| `W`/`A`/`S`/`D` | Вождение |
| `P` | Ручник |
| `L` | Фары |
| `Shift` | Выход из машины |
| ЛКМ | Стрельба, ограбление, струя из пожарного рукава |
| ПКМ | Разговор с NPC, гидрант, ключ машины |

Настройка клавиш — стандартное меню Minecraft: *Настройки → Управление*.

## 🌡 Выживание

- 💧 **Жажда** — пей воду, иначе начнёшь терять силы. Проверка: `/rmt thirst`
- 🌡 **Температура** — одевайся по погоде (форма фракций тоже греет/защищает)
- 🎒 **Рюкзак** — дополнительное место для вещей
- 🔭 **Бинокль** — приближение (прицел + использование)
- 🔦 **Фонарик** — клавиша `F` (когда нет контекстного действия)
- 📷 **Камера** — фотографии с галереей и просмотром
- 📻 **Рация** — частоты фракций для общения
- 📢 **Мегафон** — громкое объявление для окружающих

## ⛓ Полиция и розыск

- Нарушения дают **звёзды розыска** — тебя ищет полиция
- Наручники (`F` — меню действий), обыск, тюрьма, штрафы-квитанции
- **Охота**: на преступника с 5+ звёздами полиция получает метку цели —
  предложение преследования каждые 3 минуты, метка обновляется 30 секунд
- В розыске открывается приложение **«Криминал»** (даркнет) в телефоне
- Отсидел срок или заплатил штраф — розыск снят

## 🏥 Медицина

- При тяжёлом ранении игрок падает в **нокдаун** — его можно поднять (`F`,
  глядя на раненого) или вылечить предметами
- **Аптечка, бинт, шприц, дефибриллятор** — лечение в полевых условиях
- **Больница** (админы ставят точку): респавн и полное лечение
- **МЧС и Медицина**: тушение пожаров рукавом и огнетушителем, гидранты

## 🔒 Замки

Защита дверей и машин: **замок** (стандартный), **замок-PRO** (взломостойкий),
**ключи**, **ключ-карта**. Взлом — **отмычкой** или **отвёрткой**.

## 📄 Документы

Паспорт, водительские права, лицензия на оружие — оформляются и
предъявляются другим игрокам. Полицейские выдают **штраф-квитанции**,
при обыске собирают **пакеты с уликами**.
