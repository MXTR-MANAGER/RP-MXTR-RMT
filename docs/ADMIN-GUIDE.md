## 👮 Права администратора

Права выдаются вручную: администратор добавляет игрока командой
`/rmt admins` (список и управление админами). Список хранится в конфиге
на сервере.

Проверить свой статус: `/rmt admins`.

## ⌨️ Команды

### Игрокам

| Команда | Что делает |
|---|---|
| `/rmt menu` | Главное меню мода |
| `/rmt balance` | Показать баланс |
| `/rmt thirst` | Показать уровень жажды |
| `/rmt faction info` | Информация о своей фракции |
| `/rmt faction members` | Список участников фракции (лидер, до 5 приглашений) |
| `/rmt faction kick <игрок>` | Кикнуть из фракции (лидер) |
| `/rmt accept_call` | Принять вызов (фракционные вызовы) |
| `/rmt report <текст> <причина>` | Отправить репорт админам |
| `/rmt skip` | Пропустить (экран смерти / возрождение) |
| `/rmt hill` | Телепорт на холм (шутка, только для админов) |
| `/skin set <ник>` | Установить скин по нику Mojang |
| `/skin url <ссылка> [slim\|classic]` | Скин по URL через MineSkin |
| `/skin clear` | Сбросить скин |
| `/skin cape set <ссылка>` | Установить плащ по URL |
| `/skin cape clear` | Убрать плащ |

### Административные

| Команда | Что делает |
|---|---|
| `/rmt admin` · `/rmt adminpanel` | Открыть админ-панель |
| `/rmt setbalance <игрок> <сумма>` | Установить баланс игрока |
| `/rmt give <игрок> <предмет> [кол-во]` | Выдать предмет |
| `/rmt rank <игрок> <ранг>` | Установить ранг |
| `/rmt ban <игрок>` · `/rmt unban <игрок>` | Бан / разбан |
| `/rmt mute <игрок>` · `/rmt unmute <игрок>` | Мут / размут |
| `/rmt kill <игрок>` | Убить игрока |
| `/rmt heal <игрок>` | Вылечить игрока |
| `/rmt spec` | Режим наблюдателя (спектатор) |
| `/rmt admins` | Управление списком админов |
| `/rmt resetpass <игрок>` | Сбросить пароль игрока |
| `/rmt hospital` | Настройка больницы |

> Точный синтаксис подскажет игра: начни вводить команду — автодополнение
> покажет аргументы.

## 🖥 Админ-панель

Открывается через `/rmt admin` или `/rmt adminpanel`. Экраны панели:

| Экран | Что делает |
|---|---|
| **AdminPlayerScreen** | Карточка игрока: просмотр и управление |
| **AdminInvViewScreen** | Просмотр инвентаря игрока |
| **AdminInvScreen** | Редактирование инвентаря |
| **AdminItemGiveScreen** | Выдача предметов |
| **AdminMoneyScreen** | Управление балансами |
| **AdminJobGiveScreen** | Выдача работ |
| **AdminRankGiveScreen** | Выдача рангов |
| **AdminFactionGiveScreen** | Добавление во фракцию |
| **AdminLeadersScreen** | Назначение лидеров фракций |
| **AdminStaffScreen** | Управление персоналом |
| **AdminShopScreen** | Настройка магазинов |
| **AdminReportScreen** · **AdminReportChatScreen** | Просмотр репортов, чат по репорту |
| **MobSpawnSettingsScreen** | Настройки спавна мобов |
| **PrisonSetupScreen** | Настройка тюрьмы (камеры) |
| **HospitalSetupScreen** | Настройка больницы |
| **NpcSettingsScreen** · **NpcSpawnScreen** · **NpcAdminDetailScreen** | Управление NPC: спавн, имя/пол/диалог, позиция |
| **NpcShopScreen** · **NpcSellerConfigScreen** | Магазины NPC: до 15 слотов с ценами, роль продавца |
| **NpcEquipScreen** | Экипировка NPC (форма, оружие в руках) |
| **NpcBuyScreen** | Просмотр магазина NPC глазами игрока |
| **ProtectionZoneScreen** | Защищённые зоны |
| **WantedListScreen** | Список розыска |

### 🚗 Служебные машины

Служебный транспорт (Haval Dargo ДПС, Haval Dargo МВД, Пожарный КамАЗ)
не продаётся в автосалоне — сотрудники фракций берут его через меню
«Машины» по работе. Цены в конфиге `config/rmt_cars.json` (создаётся
автоматически); цена ремонта сломанных машин — у NPC-механика автосалона.

### 🧍 NPC

- NPC создаются через **яйцо спавна NPC** (`/rmt give <игрок> npc_spawn_egg`)
  или админ-панель: имя, пол, диалог, экипировка, позиция
- Роли: **продавец** (магазин до 15 слотов с ценами), **механик автосалона**
  (ремонт машин), обычный житель с диалогом
- Данные NPC хранятся в файле `rmt-npcs.json` в папке мира

## ⚙️ Конфиги

Мод хранит настройки и данные в папке `config/` на сервере. Основные файлы
создаются автоматически при первом запуске.
